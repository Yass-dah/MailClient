# MailClient
A simple Mail client Frontend App with JavaFX, to send mails and manage mails received with MVC pattern use.

This project is managed with Maven. To run it:
```
mvn clean javafx:run
```

It works as its purpose only if you have the MailServer one installed [https://github.com/Yass-dah/MailServer]

### Possible ameliorations to this project:
-  email domain registration
-  credentials on login
-  implement IMAP/SMTP communication protocol

##### <ins>Warning</ins>: always check address and port (default=<localhost, 50000>) of socket before running server or client
